Keyboard virtual yang melayang di atas aplikasi mana pun

FloatKeys adalah keyboard on-screen ala Windows touch keyboard — tapi lengkap: Shift, Ctrl, Alt, Win, F1–F12, prediksi kata ID/EN, autocorrect, clipboard history, dan custom shortcuts. Klik di mana pun, fokus tetap di aplikasi kamu.

Fitur lengkap, ukuran kecil

Semua fitur berjalan dari satu file .exe — tanpa Python, tanpa installer, tanpa admin.

💡

Prediksi kata ID/EN

Strip saran 3 kata dari kamus frekuensi 50.000 kata (Indonesia + Inggris) + model bigram next-word. Ketuk untuk melengkapi kata.

⌨️

Kunci modifier asli

Shift/Ctrl/Alt/Win dengan tap = hold, double-tap = lock. Shortcut sungguhan: Ctrl+C, Alt+Tab, Win+L — hanya dengan mouse/touch.

📌

Pin jendela di atas

Tombol Pin membuat jendela yang diketik selalu topmost (maks 8 jendela) — inti fitur PinTop, built-in tanpa app lain.

🎯

Autocorrect + highlight

teh → the otomatis; kata asing ditandai merah. Satu Backspace membatalkan koreksi, gaya HP.

📋

Clipboard history

25 item terakhir — teks & gambar (thumbnail). Termasuk screenshot Snipping Tool. Tap untuk paste, pin item penting.

⚡

Custom shortcuts (SC)

10 slot rekam kombinasi tombol, beri nama, sematkan (★) jadi strip one-tap. Tersimpan permanen di registry.

🌐

Kerja di browser

Key asli (bukan Unicode) — k/spasi play-pause YouTube, f fullscreen, m mute, semua jalan.

🗂️

Full + Compact layout

Full (~720px) dengan F1–F12 & panah, atau Compact (~460px) ala HP. Setting ukuran, opasitas, posisi diingat.

🔒

Tanpa curi fokus

WS_EX_NOACTIVATE + SendInput — klik keyboard tidak memindahkan fokus dari Notepad/browser/game kamu.

Cara pakai dalam 3 langkah

1

Download

Ambil FloatKeys.exe (~2 MB) dari tombol di atas, atau versi zip via CDN jsDelivr.

2

Jalankan

Double-click — tanpa install, tanpa runtime, tanpa admin. Windows SmartScreen? Pilih More info → Run anyway.

3

Pakai

Keyboard melayang siap. Drag bar untuk pindah, ⚙ untuk settings, ★/SC/Clip untuk tools.

Catatan: biner belum code-signed, jadi SmartScreen mungkin muncul sekali di Windows Defender. Source lengkap (keyboard.c) tersedia di GitHub — build ulang sendiri dengan Zig/MSVC bila mau.
